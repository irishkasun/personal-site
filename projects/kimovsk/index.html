О проекте

Задача

Разработать интерактивное приложение для знакомства с историческими материалами музея, используя образ «горшка без дна» — символа неисчерпаемого музейного собрания.

Главный экран задуман в виде горшка, состоящего из элементов-пазлов с названиями разделов. При выборе элемента пользователь переходит к подразделам и историческим материалам.

Моя роль

Отвечала за игровую логику, дизайн интерфейса и подготовку визуальных материалов для разработки. Подбирала иллюстраторов, готовила технические задания на отрисовку элементов приложения и согласовывала визуальные решения с заказчиком.

Что сделала

  • Изучила бриф, продумала логику взаимодействия с приложением и разработала дизайн-концепцию, которую согласовала с заказчиком.
  • Нашла иллюстраторов, собрала портфолио для выбора исполнителя и согласовала с заказчиком стиль иллюстраций.
  • Обработала фотографии музейных предметов, подобрала референсы и подготовила технические задания на отрисовку элементов приложения.
  • Спроектировала экраны и состояния интерфейса, подготовила UI-kit и материалы для передачи в разработку.
  • Протестировала игровые сценарии и работу интерфейса после реализации.

Результат

Разработан дизайн интерактивного приложения для музейного сенсорного киоска. Подготовлены визуальные материалы и UI-kit для передачи в разработку, протестированы игровые сценарии и работа интерфейса.

Визуальные материалы проекта

Для создания иллюстраций музейных предметов подготовила фотографии, референсы и технические задания для исполнителей. Согласовывала визуальный стиль и контролировала соответствие готовых элементов исходным материалам.
